# Redeem Finance ($REDEEM)

Static one-page site. No build step.

Settings live at the top of `index.html`:

- `window.CONTRACT` — $REDEEM contract address
- `window.TWITTER` — X link
- `window.BUY_URL` — buy link (button is active and shows a toast until it is set)
- `window.WC_PROJECT_ID` — WalletConnect project id (cloud.reown.com)
